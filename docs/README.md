## 需求使用规则

1. 产品范围、UI、流程、完成顺序和验收只以“当前产品需求与验收标准”为产品基线。
2. 音频需求、Prompt、YAML、JSON Schema 和使用指南是当前有效专项文档，但不得扩大、缩小或覆盖产品基线。
3. 专项文档与产品基线冲突时，以产品基线为准，并同步修订专项文档。
4. 代码中已经存在的页面、按钮和接口不自动代表需求完成，必须按照产品基线逐项验收。
