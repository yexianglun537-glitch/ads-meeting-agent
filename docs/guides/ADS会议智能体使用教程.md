# ADS 会议智能体全面使用教程

> 适用版本：首个本地 Windows 稳定产品版（React + FastAPI + SQLite）  
> 更新日期：2026-08-31
> 适用对象：项目负责人、部门负责人、会议组织者和普通团队成员  
> 当前产品基线：[`ADS会议智能体当前产品需求与验收标准.md`](../requirements/ADS会议智能体当前产品需求与验收标准.md)

## 1. 文档说明

ADS 会议智能体是一套运行在单台 Windows 电脑上的会议协作产品。它围绕一场会议完成以下闭环：

```text
建立 ADS 业务资料
  → 创建会议并关联业务上下文
  → 生成会前简报
  → 本人参加或确认委托智能体
  → 输入文字、浏览器录音或音频文件
  → 检索 ADS、判断授权并整理会议成果
  → 本人单独处理超权事项
  → 确认行动项并写回 ADS
  → 查看审计来源和减负数据
```

本产品无需账号登录，会议、工作区、模型配置、转写任务和审计记录均保存在本机。当前不提供云同步、多人在线编辑或移动端。

## 2. 选择运行方式

平台评审优先使用轻量源码包；电脑没有兼容 Python 或需要完整本地语音能力时，使用 GitHub 完整 Windows 发行版。开发人员修改代码时再使用开发模式。

| 运行方式 | 适用场景 | 是否需要开发环境 | 默认地址 |
| --- | --- | --- | --- |
| 轻量源码包 | 平台源码审查、文字输入主流程演示 | Windows 10/11 x64、Python 3.11–3.14 64 位；不需要 Node.js | `http://127.0.0.1:8000/`，占用时自动使用 8001–8010 |
| 完整 Windows 发行版 | 无兼容 Python 或需要离线转写 | 不需要开发环境 | `http://127.0.0.1:8000/` |
| 开发模式 | 修改和调试源码 | Python、Node.js | 前端 `5173`，后端 `8000` |

## 3. 启动 Windows 发行版

项目当前发行物为：

```text
dist/ADS会议智能体-0.1.0-win64.zip
```

最新完整 Windows x64 版统一从 [GitHub Releases](https://github.com/yexianglun537-glitch/ads-meeting-agent/releases) 获取。电脑没有兼容 Python，或需要随包提供的 FFmpeg、本地转写和说话人分离能力时，使用该版本。

### 3.1 解压并启动

1. 将 ZIP 完整解压到一个有写入权限的本地目录，不要直接在压缩包内运行。
2. 保证解压磁盘至少有 1 GB 可用空间。
3. 双击 `ADS会议智能体.exe`。
4. 启动器检查前端文件、FFmpeg、本地 Whisper 模型、磁盘空间、目录写入权限和端口。
5. 检查通过后，系统自动打开 `http://127.0.0.1:8000`。

发行版已经内置 Python 运行环境、前端文件、FFmpeg、`faster-whisper-small`、`sherpa-onnx` 和匿名说话人分离模型，不要求电脑预装 Python、Node.js、Git、FFmpeg、Whisper 或 PyTorch。

### 3.2 端口被占用

默认端口 `8000` 被其他程序占用时，在发行目录打开 PowerShell 7，执行：

```powershell
.\ADS会议智能体.exe --port 18080
```

随后访问：

```text
http://127.0.0.1:18080
```

### 3.3 不自动打开浏览器

```powershell
.\ADS会议智能体.exe --no-browser
```

### 3.4 停止发行版

关闭 `ADS会议智能体.exe` 所在的命令窗口，或在该窗口按 `Ctrl+C`。不要在数据库写入或音频转写过程中强制结束进程。

## 4. 启动轻量源码包

### 4.1 一键启动

运行条件：Windows 10/11 x64，已安装 Python 3.11–3.14 的任一 64 位版本。轻量源码包已经包含前端生产文件和离线 Python wheel，不需要 Node.js、npm、PowerShell、Rust、Cargo、管理员权限或首次联网安装。

在项目根目录双击：

```text
启动项目.bat
```

也可以在命令提示符（CMD）中运行：

```bat
start-dev.cmd
```

脚本会检查 Python、创建或校验虚拟环境、从包内 wheelhouse 离线安装依赖，并启动单个前后端服务：

```text
http://127.0.0.1:8000/
```

8000 被占用时，启动器自动选择 8001–8010 中第一个可用端口；以命令窗口显示并自动打开的实际地址为准。不要关闭启动窗口，停止时在该窗口按 `Ctrl+C`。

轻量源码包可以使用本地规则和文字输入完成会议主流程。本地语音组件未随轻量源码包提供，不包含 FFmpeg、本地转写、说话人分离运行时或语音模型；设置页显示组件不可用是正常边界，演示时继续使用文字输入。Python 3.13 x64 可在启动后主动点击“一键配置语音”；其他版本查看[轻量源码版升级完整语音说明](轻量源码版升级完整语音说明.md)，其完整语音能力不属于逐版已验证范围。

如果没有兼容 Python，请不要现场安装编译工具，直接改用 [GitHub Releases 完整 Windows x64 版](https://github.com/yexianglun537-glitch/ads-meeting-agent/releases)。

### 4.2 开发维护模式

以下命令仅供开发维护人员，不是评委运行轻量源码包的步骤。开发模式会使用 Node.js 和前端 5173 端口。

后端：

```powershell
Set-Location backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

另开一个 PowerShell 7 窗口启动前端：

```powershell
Set-Location frontend
npm ci
npm run dev -- --host 127.0.0.1
```

## 5. 首次启动与旧数据迁移

### 5.1 全新安装

首次进入产品时，填写：

| 字段 | 用途 |
| --- | --- |
| 你的姓名 | 本人身份、代理身份和审计记录 |
| 岗位或职责 | 标识你在团队中的职责 |
| 团队工作区名称 | 建立第一个 ADS 业务工作区 |
| 工作区说明 | 说明团队、部门或业务范围 |

首次配置不要求选择模型或填写 API Key，系统先使用默认本地规则。填写后点击 `完成配置并检查 AI 分身`。系统只创建本人身份和空白工作区，不会自动加入会议、项目或任务；随后进入 `智能体中心`，自动生成当前用户本人的身份说明。请检查和修改后保存，其他团队身份需要时再手工新增。在线模型统一在进入产品后的 `设置 → 模型服务` 中配置。

### 5.2 检测到旧数据库

升级旧版本时，系统可能显示“发现旧版本数据”：

- `继续使用已有工作区`：保留并继续使用已有业务数据。
- `创建新的空白工作区`：保留旧工作区，同时创建新的空白工作区作为当前起点。

选择前建议先保留旧数据目录的副本。系统不会在迁移时自动删除旧工作区。

## 7. 建立 ADS 工作区

ADS 工作区代表一个团队或业务单元，不代表单一会议。会议中的检索、授权判断、问答和任务写回都依赖这里的数据。

### 7.1 推荐录入顺序

```text
成员 → 项目 → 目标 → 指标 → 风险 → 任务 → 制度 → 历史立场 → 授权
```

先建立成员，再录入需要选择负责人的其他对象，可以减少后续返工。

### 7.2 工作区操作

1. 点击左侧 `ADS`。
2. 使用 `ADS 工作区` 下拉框切换当前工作区。
3. 点击 `新建工作区` 创建新的空白工作区。
4. 点击 `归档工作区` 标记不再使用的工作区。
5. 选择已归档工作区后，点击 `恢复工作区` 重新启用。

当前界面没有永久删除工作区按钮。归档不会删除工作区中的业务对象和历史来源。

### 7.3 ADS 页签和字段

| 页签 | 记录内容 | 关键字段 |
| --- | --- | --- |
| 概览 | 工作区摘要 | 成员、目标、进行中任务、授权规则数量 |
| 成员 | 团队人员 | 姓名、岗位或职责 |
| 项目 | 项目或专项 | 名称、说明、状态、负责人 |
| 目标 | 业务目标 | 目标名称、进度、衡量指标、当前风险 |
| 指标 | 可量化指标 | 指标名称、当前值、目标值、单位、所属目标 |
| 风险 | 已知风险 | 标题、影响、负责人、状态、所属项目 |
| 任务 | 业务任务 | 名称、负责人、截止日期、状态 |
| 制度 | 标准和约束 | 制度标题、内容、适用范围 |
| 历史立场 | 人员过往立场 | 人员、主题、历史立场、生效范围 |
| 授权 | 智能体代理边界 | 授权人、授权范围、允许操作、必须升级条件 |

### 7.4 新建和编辑对象

1. 切换到目标页签。
2. 点击右上角 `新建成员`、`新建项目` 等按钮。
3. 填写字段后点击 `保存`。
4. 点击已有对象所在行，可以重新打开编辑窗口。
5. 点击 `取消`、右上角关闭图标或弹窗外空白区域可放弃本次编辑。

列表中的对象 ID 用于来源追溯。会议现场、决策中心、智能体回答或审计页出现来源 ID 时，点击它会跳到对应 ADS 对象；对象已不存在时会明确提示。

### 7.5 授权规则写法

授权范围要能区分“允许智能体直接处理”和“必须由本人决定”的事项。例如：

```text
授权范围：允许说明已有任务进度、确认既定排期、要求补充已登记风险。
允许执行：查询目标；说明任务状态；提供既有制度内容。
必须升级：新增预算；改变技术路线；变更验收范围；延期超过 3 天。
```

授权规则越具体，代理行为越容易复核。不要只写“全权处理”。

## 8. 配置模型和本地语音

建议在创建第一场会议前完成本节检查。

### 8.1 本地规则模式

本地规则模式不需要网络和 API Key，可用于离线完成基础会议流程。当前运行方式可在 `设置 → 模型服务` 和模型调用审计中检查。

发行启动器和开发环境默认使用：

```env
USE_MOCK_AI=true
```

此时即使设置页保存了在线模型，会议分析仍由本地规则执行。

### 8.2 配置在线模型

1. 进入 `设置 → 模型服务`。
2. 在已有模型中填写 `服务地址`、`模型名称` 和 `API Key`。
3. 勾选 `启用`。
4. 需要作为默认模型时，选择 `设为默认`。
5. 点击 `保存配置`。
6. 点击 `测试连接`，确认页面返回连接正常。
7. 在模型列表和 `模型调用审计` 中检查当前模型、调用状态与实际 Provider。

如果列表中没有目标 Provider，可在 `添加模型服务` 中点击对应服务名称，加入配置列表后再填写密钥。

常用填写示例：

| 类型 | 服务地址 | 模型名称 | 说明 |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` | 使用 DeepSeek 平台签发的 API Key |
| OpenAI 兼容服务 | 服务商提供的 API 根地址 | 服务商公布的模型标识 | 地址、模型和 Key 必须属于同一服务商 |

不要把模型官网、控制台网页地址或聊天页面地址填入“服务地址”。页面中的 `测试连接` 用来验证地址、模型和 Key 是否能够完成一次兼容调用。

API Key 只保存在本机后端。页面不会回显完整密钥，留空保存表示保留原密钥。

### 8.3 允许在线模型实际参与工作流

轻量源码包或开发模式：把 `backend/.env` 中的配置改为：

```env
USE_MOCK_AI=false
```

保存后重启产品；轻量源码包仍由同一个启动窗口提供前端和后端。

发行版：先停止已经运行的产品，再在发行目录用 PowerShell 7 启动：

```powershell
$env:USE_MOCK_AI = "false"
.\ADS会议智能体.exe
```

设置页的 `测试连接` 只证明服务连接，不等于会议分析已经使用该模型。请再提交一条真实会议发言，并在 `模型调用审计` 中核对 Provider、模型、状态、耗时、Token 和 Prompt 版本。

### 8.4 检查本地语音

完整 Windows 发行版已经随包提供语音组件。轻量源码包默认不包含这些组件，应优先使用文字输入完成主流程。

在 Python 3.13 x64 轻量源码版中，可进入 `设置 → 本地语音` 点击 `一键配置语音`。此操作只有用户点击后才联网，需预留约 1.5 GB 磁盘空间；下载和安装失败不会影响文字输入。页面显示“配置完成，请重启 ADS”后，返回启动窗口按 `Ctrl+C`，重新双击 `启动项目.bat`。

Python 3.11、3.12、3.14 只承诺轻量文字启动范围，完整语音未逐版本实际验收。若确需配置，按照[轻量源码版升级完整语音说明](轻量源码版升级完整语音说明.md)操作并以健康接口结果为准。

进入 `设置 → 本地语音`，应看到：

```text
组件可用
FFmpeg：可用
Whisper 模型：可用
```

也可以访问：

```text
http://127.0.0.1:8000/api/speech/health
```

只有 `status` 为 `ready`，且 `ffmpeg_available`、`model_available` 均为 `true`，才表示离线转写已就绪。第一次转写需要加载本地模型，通常比后续任务慢。

## 9. 创建会议

### 9.1 填写会议信息

1. 点击左侧 `创建` 或工作台的 `新建会议`。
2. 填写 `会议名称`。
3. 选择 `开始时间` 和 `结束时间`。
4. 输入 `参会人员`。
5. 需要固定周期时，在 `重复` 中选择 `每周`、`每两周` 或 `每月`，并设置不超过一年的 `循环截止日期`。

时间要求：

- 结束时间必须晚于开始时间；
- 会议时长最短 5 分钟；
- 会议时长最长 8 小时。

参会人员可以使用顿号、中文逗号、英文逗号或换行分隔，系统会去除空值和重复姓名。

### 9.2 填写会议内容并整理议程

1. 在 `业务工作区` 中选择本次会议所属团队。
2. 查看成员、目标、任务和授权数量是否符合预期。
3. 在 `会议内容` 中自由描述要讨论、确认和推进的事项。
4. 点击 `AI 自动整理`，系统会按会议总时长生成结构化分段议程。
5. 在线模型不可用时会自动回退到本地规则；生成结果仍可在创建前继续修改。

### 9.3 选择参会方式

`本人参加`：

- 本人参与会议；
- 智能体负责转写、整理、问答、纪要和任务提取；
- 智能体不会自动代表本人发言。

`委托智能体`：

- 必须从当前工作区成员中选择 `代理身份`；
- 必须至少勾选一条 `本场授权`；
- 开启 `授权内自动回复` 后，智能体可以在授权范围内自动形成回复；
- 关闭自动回复时，只生成回复建议；
- 超权事项始终交给本人确认。

最后选择 `使用模型`，点击 `创建并生成会前简报`。字段有误时，页面会显示具体错误；会议不会被创建。创建成功后草稿会被清空，避免下一场会议继承上一场的时间、内容或议程。

## 10. 使用会议工作空间

会议工作空间包含 `概览`、`会前准备`、`会议现场`、`会议成果`、`审计与来源` 五个页签。页面不再固定显示右侧 ADS 智能体侧栏，主内容会使用完整可用宽度。

进入 `现场` 前，先在顶部 `当前会议` 中核对并选择会议。切换到另一场会议时，如果当前会议还有未提交文字，系统会先询问是否丢弃；取消会留在原会议，确认后才会清空文字并切换。录音过程中切换会议也会先确认，避免发言或录音误投到其他会议。

会议标题右侧的 `编辑会议信息` 可修改名称、时间、参会人、会议内容和参与方式。循环会议保存时选择 `仅本次` 或 `本次及后续`；已开始或结束的会议会锁定结构字段。

### 10.1 概览

这里集中显示：

- 会议状态和代理状态；
- 已识别决策和行动项数量；
- 会议目标和关联 ADS 目标；
- 需要本人处理的事项；
- 最近审计活动。

点击 `返回会议现场` 可以回到当前会议输入区。

### 10.2 会前准备

1. 没有简报时，点击 `生成会前简报`。
2. 阅读简报、建议议程、本场授权和必须升级条件。点击 `编辑建议议程` 可修改议题、分钟、背景和建议问题。
3. 本人参加的会议可直接进入会议现场。
4. 委托会议点击页面上方的 `开始会议` 后，代理才正式开始。
5. 代理运行中可点击 `暂停智能体`。
6. 暂停后点击 `继续智能体` 恢复处理。

主动暂停智能体会禁用新的会议分析；超权待确认只挂起对应事项，不会自动暂停整场会议。

人工保存议程后，后台不会自动覆盖。再次点击 `重新生成` 时会出现覆盖确认；取消确认会保留人工内容。

### 10.3 文字输入

1. 打开 `会议现场`。
2. 选择 `文字输入`。
3. 按 `发言人：内容` 输入本次新增发言。
4. 点击 `提交给智能体`。

示例：

```text
李娜：当前联调进度为 80%，计划周五完成。
王强：建议增加一项采购预算，需要负责人确认。
```

每次只提交新增发言。系统会更新：

- 逐条会议时间线；
- ADS 检索来源；
- 智能体处理动作；
- 授权判断；
- 决策、风险和行动项；
- 建议回复或已发送回复。

出现超权事项时，该事项进入决策中心。你可以返回原会议继续提交其他授权内发言，不必等待该事项处理完毕。

### 10.4 浏览器录音

建议使用支持 `MediaRecorder` 的最新 Chrome 或 Edge。

1. 在会议现场选择 `录音与音频`。
2. 确认顶部显示 `本地转写可用`。
3. 点击 `开始录音`。
4. 浏览器请求麦克风权限时选择允许。
5. 查看麦克风权限、录音时长和实时音量。
6. 点击 `暂停` 可暂时停止采集。
7. 点击 `继续` 恢复录音。
8. 点击 `结束并转写`，录音会上传到本机后端并进入转写队列。
9. 如果不需要保留本次录音，点击 `取消录音`；系统会丢弃尚未提交的录音并释放麦克风。

录音期间刷新、关闭、切换左侧页面、搜索打开其他会议或从来源下钻离开时，产品会给出确认。取消离开会保留当前录音；确认离开会取消未结束录音并释放麦克风。同一时间只有一场会议可以占用麦克风；另一场会议尝试录音时会显示占用提示。

### 10.5 上传音频文件

可以把文件拖到上传区域，或点击 `选择文件`。

支持格式：

```text
MP3、WAV、M4A、WebM、MP4、FLAC
```

限制：

- 单个文件不超过 500 MB；
- 音频时长不超过 4 小时；
- 文件不能为空且必须能够被 FFmpeg 读取。

长音频会在后台处理。处理期间可以继续查看会议内容或切换到其他会议。

上传或录音前可以设置：

- `区分不同发言人`：默认开启；关闭后只做转写，所有自动片段使用“发言人 1”；
- `说话人数`：默认 `自动判断`，已知人数时可以选择 2～10 人；
- 所有处理均在本机完成，匿名标签不会识别真实姓名，也不会跨会议关联声纹。

### 10.6 音频任务状态和按钮

| 状态 | 含义 | 可用操作 |
| --- | --- | --- |
| 已上传 | 文件已经保存到本机 | 等待处理、取消 |
| 预处理 | FFmpeg 正在标准化音频 | 查看进度、取消 |
| 转写中 | faster-whisper 正在识别 | 查看进度、取消 |
| 区分发言人 | sherpa-onnx 正在生成匿名标签 | 查看进度、取消 |
| 待审核 | 已生成可编辑转写 | 编辑并确认、删除任务 |
| 已确认 | 已进入统一会议分析 | 查看记录 |
| 失败 | 转写未完成，显示错误 | 重新转写、删除任务 |
| 已取消 | 用户停止任务 | 重新转写、删除任务 |

音频任务右侧图标：

- `取消转写`：停止正在处理的任务；
- `重新转写`：用保留的原始音频重新执行；
- `删除任务`：删除未确认任务及其未确认转写，操作前会确认。

原始音频已被清理时，任务不能重新转写。

### 10.7 审核转写

1. 在任务列表中选择状态为 `待审核` 的任务。
2. 在 `完整转写` 中修正总稿。
3. 在片段列表中修改 `发言人` 和 `转写片段`。
4. 出现 `重叠发言，建议人工核对` 时，回听对应时间并修正发言人或文字。单音轨同时讲话不能保证两个人的内容都完整转写。
5. 如果说话人分离失败，页面会保留转写并回退为“发言人 1”，可以人工修改后继续确认。
6. 输入框失去焦点时自动保存修改。
7. 点击 `确认并进入智能分析`。

只有完成最后一步，转写才会进入会议分析、授权判断、决策和行动项流程。原始文本和修订记录会保留用于追溯。

## 11. 使用智能体中心

点击左侧 `智能体` 进入智能体中心。这里集中显示当前身份、代理中会议、可用模型、本人身份列表、代理会话和授权来源。

### 11.1 管理本人身份

1. 首次配置完成后，检查系统为当前用户生成的身份说明。
2. 需要修改时编辑姓名、岗位职责和身份说明并保存。
3. 需要其他代理身份时点击新增身份；系统不会自动为 ADS 中的其他成员创建身份。
4. 切换当前身份后，后续代理和审计使用新的活动身份。

### 11.2 查看代理和模型

- 在代理会话列表检查当前会议、代理状态和授权来源；
- 点击 `模型设置` 进入统一模型配置入口；
- 会议处理的判断、授权、本人决定和来源证据分别在会议页签、决策中心与审计页查看，不在会议详情复制固定侧栏。

## 12. 处理超权决策

### 12.1 找到待处理事项

1. 点击左侧 `决策`。
2. 使用 `待处理`、`已处理`、`全部` 切换列表。
3. 点击左侧事项，在右侧查看完整上下文。

`pending` 和 `deferred` 都属于未解决事项。队列优先显示待处理项，再按回复时限和创建时间排序。

右侧会展示：

- 来源会议和收到时间；
- 需要确认的问题和回复时限；
- 超出授权的原因；
- 当前授权、关联目标和风险；
- AI 建议与可能影响；
- 来源对象是否仍然存在。

点击 `进入会议` 可打开来源会议。

### 12.2 四种处理方式

| 按钮 | 结果 |
| --- | --- |
| 同意建议 | 使用 AI 建议作为本人决定，返回原会议 |
| 修改后回复 | 使用“给会议的回复”中编辑后的内容返回原会议 |
| 拒绝 | 不执行该超权内容；必须填写拒绝理由 |
| 暂不处理 | 保存为待后续处理，仍可再次打开并决定 |

处理后，原会议时间线会出现 `本人决定已返回会议`，并记录实际回复和时间。处理一个事项不会改变其他会议的输入和结果。

`拒绝` 后，原提案及其行动项会从会议成果中移除；`修改后回复` 会用本人填写的回复替换原提案，作为新的有效决策。原始发言、原提案、本人回复和处理时间不会丢失，仍保留在 `审计与来源` 中。

## 13. 检查会议成果并写回 ADS

打开 `会议成果`，依次检查：

- `结构化纪要`；
- `本场可核验数据`；
- 已提取的决策和证据；
- 每条行动项、负责人和截止日期。

结构化纪要根据当前有效决策和行动项重新生成，不会连续追加旧版“补充记录”。已拒绝或修改前的提案不会继续出现在会议成果与导出内容中，需要追溯时请到 `审计与来源` 查看。

### 13.1 逐条写回

1. 为行动项选择当前工作区中的负责人。
2. 填写有效截止日期。
3. 点击 `写回此项`。
4. 写回失败时查看错误、尝试次数和任务 ID。
5. 修正数据后点击 `重试写回`。

行动项状态：

- `信息不完整`：缺少有效负责人或截止日期；
- `待写回`：信息完整，可以写回；
- `写回失败`：保留错误和尝试次数，可重试；
- `已写回`：已经生成或更新 ADS 任务，不能重复写回。

### 13.2 批量写回

点击 `批量写回可用行动项`，系统只处理当前信息完整且尚未写回的行动项。一个行动项失败不会清除其他成功项。

所有行动项成功写回后，会议才进入 `已闭环`。写回的 ADS 任务会保留会议来源和审计关系。

## 14. 查看审计与来源

在 `审计与来源` 页签中，可以查看：

```text
原始发言 → 转写片段 → 智能体判断 → 授权依据 → 决策 → 行动项 → ADS 任务
```

审计页按三个业务区回放：`原始输入与判断`、`回复、授权与本人决定`、`决策、行动项与写回`。原始音频任务会显示时间片和修订次数；回复、升级、本人实际回复、决策和 ADS 任务保持关联。被拒绝或修改前的旧提案只作为历史证据保留在原始输入、升级记录和事件时间线中，不再进入当前会议成果。事件时间线另行记录会前准备、会议分析、转写确认、代理控制、本人决定和任务写回。点击 `可下钻 ADS 来源` 中的对象 ID，可以打开对应 ADS 对象。

## 15. 管理多场会议

### 15.1 切换会议

- 在工作台点击 `近期会议`；
- 在左侧 `会议` 页面点击时间线中的会议；
- 决策中心点击 `进入会议`；
- 顶部搜索并点击会议结果。

每场会议分别保存模型、授权、代理状态、发言、决策和成果，切换不会覆盖其他会议。

### 15.2 一人多会

可以让本人参加会议 A，同时委托智能体处理会议 B。会议 B 的超权事项进入统一决策中心时：

- 会议 A 仍可继续输入；
- 会议 B 仍可处理其他授权内发言；
- 本人决定只返回会议 B；
- 两场会议分别生成纪要和行动项；
- 同一麦克风仍只能由其中一场会议占用。

工作台和 `会议` 页面会标记时间重叠的活动会议。边界刚好相接的两场会议不算重叠；已结束、已关闭和已取消会议不参与冲突提醒。

## 16. 管理会议列表

点击左侧 `会议` 查看全部会议。点击任意时间线行可进入该会议。

展开 `清理旧会议` 后，只显示已结束、已关闭、已取消或计划时间已过的会议。点击对应 `删除` 会要求确认，并同时删除该会议的转写任务和音频。

删除会议不可通过界面撤销。重要数据应先在设置中创建数据库备份，并另行保留需要的原始音频。

## 17. 设置与本地数据管理

### 17.1 模型调用审计

`设置 → 模型调用审计` 最多显示最近 20 条记录，包括：

- Provider 和模型；
- 操作名称；
- 成功、本地降级或失败；
- 调用耗时；
- Token 用量；
- Prompt 版本；
- 错误信息。

审计记录不会显示完整 API Key。

### 17.2 减负基准与 Markdown 报告

可以在 `数据看板` 点击 `录入人工基准`，直接定位到 `设置 → 减负基准与单场下钻`：

1. 选择一场已经完成分析的真实会议；
2. 选择会议类型；
3. 填写人工处理分钟和系统后处理分钟；
4. 填写样本日期、计时来源和必要说明；
5. 点击 `保存人工基准`。

保存后，左侧 `数据看板` 按当前选择的工作区和日期范围显示汇总结果。会议过程数据按会议开始日期统计；人工对照必须关联入选会议，并按样本日期统计。综合节省比例使用“（总人工处理分钟－总系统后处理分钟）÷ 总人工处理分钟”，不是各场比例的简单平均。页面 `指标口径` 区域会持续显示这些定义。点击 `下载 Markdown 报告` 可以导出口径、来源和逐条样本；没有实际人工计时的数据不会推算节省比例。

### 17.3 原始音频保留期

可选择：

- `长期保留`：不按时间自动清理；
- `30 天`：终态音频达到 30 天后清理；
- `90 天`：终态音频达到 90 天后清理。

产品启动时会按所选期限检查过期音频。自动清理只处理失败、取消或已确认任务的原始音频，不删除转写文本和审计记录。

### 17.4 创建备份

点击 `创建备份`，系统在本地备份目录生成 SQLite 数据库副本。备份包含数据库中的会议、工作区、设置、转写元数据、审计数据和已保存的模型密钥，但不复制原始音频二进制文件。备份文件应按敏感数据保管，不要上传到公开位置。

### 17.5 从备份恢复

1. 在 `恢复本地备份` 中选择备份文件。
2. 点击 `从所选备份恢复`。
3. 阅读覆盖提示并确认。
4. 页面刷新后核对工作区、会议和设置。

恢复会用备份数据库覆盖当前业务数据库。数据库记录引用的原始音频如果已经被清理，恢复数据库也不会重新生成音频文件。

### 17.6 清理音频

点击 `清理音频` 并确认后，系统删除失败、取消和已确认任务的本地音频，保留转写文本、修订和审计记录。清理后相关任务不能依赖原始文件重新转写。

### 17.7 按会议删除

展开 `按会议删除数据`，点击会议名称并确认。系统删除该会议及其音频任务，不影响其他会议和工作区。

### 17.8 恢复空白数据

点击 `恢复空白数据` 并确认后，系统删除：

- 全部会议；
- 全部 ADS 工作区；
- 全部语音任务；
- 本地音频。

这是高风险操作。执行前至少创建数据库备份；需要保留的音频应另外复制到安全目录。

## 18. 推荐的首次完整使用流程

1. 启动产品，完成本人身份和空白工作区初始化。
2. 选择本地规则或配置在线模型；只有完整发行版需要确认本地语音可用，轻量源码包使用文字输入。
3. 在 `ADS` 依次建立成员、项目、目标、指标、风险、任务、制度、历史立场和授权。
4. 在 `创建` 填写一场真实会议，选择本人参加或委托智能体。
5. 查看会前简报；确认无误后点击页面上方的 `开始会议`。
6. 在会议现场提交一条普通进度发言。
7. 再提交一条超出授权范围的发言。
8. 返回会议继续输入其他授权内内容。
9. 在 `决策` 中处理超权事项。
10. 使用浏览器录音或上传一段短音频，审核后点击 `确认并进入智能分析`。
11. 在右侧询问一个只依赖当前 ADS 资料的问题，并检查来源。
12. 在 `会议成果` 中补全行动项，先逐条写回，再检查 ADS 任务。
13. 在 `审计与来源` 中检查完整来源链。
14. 在 `设置` 录入真实人工基准并下载 Markdown 报告。
15. 在 `设置` 创建数据库备份。

## 19. 常见问题

### 19.1 页面无法打开

轻量源码包和完整发行版检查命令窗口显示的实际端口；默认地址为：

```text
http://127.0.0.1:8000/api/health
http://127.0.0.1:8000/
```

轻量源码包会在 8000 被占用时自动选择 8001–8010。若命令窗口显示其他端口，请将上面地址中的 8000 替换为实际端口。开发模式才需要另外检查前端 5173。

### 19.2 前端提示无法连接后端

检查启动窗口是否仍在运行。轻量源码包或完整发行版查看 `logs/ads-agent.log`；开发模式查看：

```text
logs/backend.log
```

### 19.3 创建会议失败

依次检查：

- 会议名称是否为空；
- 开始、结束时间是否完整且顺序正确；
- 时长是否在 5 分钟到 8 小时之间；
- 是否已选择业务工作区；
- 委托模式是否选择了代理身份；
- 委托模式是否至少选择了一条本场授权。

### 19.4 无法提交会议发言

- 先完成会前简报；
- 委托会议先点击页面上方的 `开始会议`；
- 智能体被主动暂停时，先点击 `继续智能体`；
- 检查是否正在分析上一批发言。

单个超权待确认事项不会阻止其他授权内发言。

### 19.5 麦克风无法使用

1. 检查浏览器地址栏的网站麦克风权限。
2. 在 Windows“设置 → 隐私和安全性 → 麦克风”允许浏览器访问。
3. 确认另一场会议没有正在录音。
4. 刷新页面后重试。
5. 仍无法使用时，改用上传音频或文字输入。

### 19.6 本地转写组件未就绪

轻量源码包不包含本地语音组件，出现未就绪提示是正常边界，请继续使用文字输入。需要离线转写时，改用 [GitHub Releases 完整 Windows x64 版](https://github.com/yexianglun537-glitch/ads-meeting-agent/releases)。

完整发行版或自行配置语音资源的开发环境可确认：

```text
runtime/ffmpeg/bin/ffmpeg.exe
runtime/ffmpeg/bin/ffprobe.exe
backend/data/models/faster-whisper-small/model.bin
```

然后查看 `/api/speech/health` 返回的具体缺失项。完整发行版缺少这些内部文件时，应重新完整解压发行包。

### 19.7 转写失败

- 确认文件格式受支持且不是空文件；
- 确认文件不超过 500 MB、时长不超过 4 小时；
- 先用短、清晰的普通话音频复核流程；
- 点击 `重新转写`；
- 原始文件已清理时重新上传；
- 查看开发版 `logs/backend.log` 或发行版 `logs/ads-agent.log`。

### 19.8 模型连接正常，但回答仍显示本地规则

检查 `USE_MOCK_AI`。值为 `true` 时，会议工作流强制使用本地规则。改为 `false` 并重启产品，再从会议提交新发言，并核对模型调用审计。

### 19.9 无法写回行动项

常见原因：

- 行动项负责人不属于当前 ADS 工作区；
- 截止日期为空或无效；
- 该项状态仍是 `信息不完整`；
- 会议中仍有未解决的超权事项；
- 该项已经写回；
- 后端写回失败，需要根据错误修正后点击 `重试写回`。

### 19.10 减负成效一直显示待采集

系统只显示可从当前会议记录核验的过程数量。没有录入真实人工基准时，改造前时长和节省比例保持 `待采集`，这是正常状态。

## 21. 当前能力边界

### 21.1 已提供的产品能力

- 本地单用户、多个 ADS 工作区和多场会议；
- 会前简报、文字输入、浏览器录音和文件转写；
- 本地 FFmpeg、`faster-whisper-small` 与 sherpa-onnx 匿名说话人分离；
- 本人参加和委托智能体；
- 授权内建议/自动回复和超权单项升级；
- 决策返回原会议，其他会议输入不被阻塞；
- 结构化纪要、行动项独立写回、失败重试；
- 来源下钻、审计、数据库备份和音频清理；
- 本人身份新增、编辑与切换，会议时间重叠提示；
- 真实计时基准、单场减负指标和 Markdown 指标报告；
- 浏览器/Windows 原生中文 TTS。

### 21.2 当前不提供

- Teams、Zoom、腾讯会议等外部会议平台接入；
- 登录、多租户、企业账号权限和局域网多人编辑；
- 移动端适配、云同步、自动更新和正式安装器；
- 视频会议、摄像头和自动入会机器人；
- 实时连续字幕、真实姓名识别、跨会议声纹关联、重叠发言双路完整转写和语音克隆；
- 工作区永久删除入口；
- 会议 Markdown 报告的界面导出入口。

### 21.3 尚未完成外部验收的部分

- 真实 DeepSeek 和 OpenAI-compatible 密钥的完整会议处理；
- 1366×768、1920×1080 已完成本机浏览器布局检查；仍需用户在目标显示器核对字体缩放和实际操作手感；
- 三组真实会议的人工处理基准与减负对照；
- MP3、WAV、M4A、WebM 等真实音频的完整人工矩阵；
- 完全没有开发环境和模型缓存的干净 Windows 电脑断网验收；
- 正式外部分发前的完整第三方许可证复核。

`智能体` 独立页面用于管理本人身份、代理会话、授权来源和模型入口；会议详情不再提供固定右侧智能体面板。

## 22. 管理员与开发验证命令

以下命令仅供开发维护人员，不是评委运行轻量源码包的步骤。只修改业务数据时不需要运行；升级源码或重新制作发行版后，应执行：

```powershell
Set-Location frontend
npm test
npm run typecheck
npm run build

Set-Location ..\backend
.\.venv\Scripts\python.exe -m pytest tests -q
```

构建 Windows 发行版：

```powershell
Set-Location ..
.\packaging\build-release.ps1 -Version 0.1.0
```

检查发行目录结构、启动、首页、健康接口和本地语音：

```powershell
.\packaging\verify-release.ps1 -ReleaseDir '.\dist\ADS会议智能体' -Port 18081
```

验证命令通过只说明对应代码、构建或本机运行检查通过，不能替代真实模型、真实音频、双分辨率视觉和干净 Windows 环境验收。
