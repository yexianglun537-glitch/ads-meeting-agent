# ADS 轻量源码版升级完整语音说明

## 1. 先确认是否需要升级

轻量源码版无需语音组件，也能用文字输入完成创建会议、会前简报、会议分析、超权确认、行动项写回和审计查看。限时评审优先使用文字模式。

完整语音包含 FFmpeg、Whisper 转写、匿名说话人分离及其本地模型。Whisper 只负责语音转文字，不负责会议分析和代理回复；DeepSeek/OpenAI 兼容模型需在“设置 → 模型服务”单独配置。

## 2. 版本支持边界

| Python | 轻量文字启动 | 完整语音配置方式 | 当前结论 |
| --- | --- | --- | --- |
| 3.13 x64 | 支持 | 页面“一键配置语音” | 本机优先支持和验收范围 |
| 3.11 x64 | 支持 | 手动命令 | 完整语音未逐版验收 |
| 3.12 x64 | 支持 | 手动命令 | 完整语音未逐版验收 |
| 3.14 x64 | 支持 | 手动命令 | 已有轻量启动结果；完整语音未验收 |

任何版本都不得用“依赖下载成功”替代健康接口和真实音频验证。

## 3. Python 3.13 x64 一键配置

准备条件：

- 已双击 `启动项目.bat` 并能打开 ADS；
- 网络可以访问 PyPI、Hugging Face、GitHub 和 FFmpeg 下载站；
- 解压目录可写；
- 建议预留至少 1.5 GB 磁盘空间；
- 配置期间不要关闭启动窗口。

操作步骤：

1. 在首次启动页“本地语音”旁，或 `设置 → 本地语音` 中点击 `一键配置语音`。
2. 等待状态依次显示安装依赖、下载资源和检查依赖。
3. 失败时可继续使用文字输入；检查网络后点击重试。
4. 显示“配置完成，请重启 ADS”后，返回启动窗口按 `Ctrl+C`。
5. 重新双击 `启动项目.bat`。
6. 在 `设置 → 本地语音` 检查 FFmpeg、Whisper 和组件状态。

一键配置不会安装或替换系统 Python，不会接收浏览器传入的命令或下载地址，也不会自动结束正在运行的 ADS。

## 4. Python 3.11、3.12、3.14 手动配置

这些版本保留轻量文字模式，但完整语音依赖没有逐版本实际验收。请先接受“可能因第三方 wheel 尚未提供而安装失败”的边界，再执行以下步骤。

1. 先双击 `启动项目.bat`，确认轻量版能启动，然后在启动窗口按 `Ctrl+C` 停止。
2. 在解压目录打开 CMD。
3. 只安装二进制 wheel，避免现场编译：

```bat
backend\.venv\Scripts\python.exe -m pip install --disable-pip-version-check --only-binary=:all: -r backend\requirements.txt
```

4. 下载固定语音资源：

```bat
backend\.venv\Scripts\python.exe backend\tools\download_runtime_assets.py
```

5. 检查核心模块：

```bat
backend\.venv\Scripts\python.exe -c "import faster_whisper, sherpa_onnx, numpy; print('speech imports ok')"
```

6. 重新双击 `启动项目.bat`，打开健康接口：

```text
http://127.0.0.1:8000/api/speech/health
```

若 8000 被占用，以启动窗口显示的实际端口为准。只有接口返回 `status: ready`，且 `ffmpeg_available`、`model_available`、`diarization_available` 均为 `true`，才能继续真实音频测试。

## 5. 常见失败处理

- `No matching distribution found`：当前 Python 没有某个第三方二进制 wheel。不要安装 Rust/Cargo 现场编译；继续使用文字模式，或改用 GitHub 完整 Windows x64 版。
- 下载中断：保留 `.part` 文件后重新运行下载命令，下载器会尝试续传。
- 路径过长：把整个项目解压到更短目录，例如 `D:\ADS`，再重新创建 `backend\.venv`。
- 健康接口不是 `ready`：根据返回信息分别检查 FFmpeg、Whisper 模型和说话人分离模型，不要仅凭 import 成功判定可用。
- 安装失败：不会破坏会议文字数据；重新启动后仍可切回文字输入。

无需配置环境时，可直接使用 [GitHub Releases 完整 Windows x64 版](https://github.com/yexianglun537-glitch/ads-meeting-agent/releases)。
