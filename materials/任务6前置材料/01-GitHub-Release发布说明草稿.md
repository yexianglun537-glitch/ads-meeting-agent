## 版本说明

ADS 会议智能体用于完成“会前聚合 → 会中协作/代理参会 → 会后任务闭环”。本次完整 Windows x64 版面向没有兼容 Python 环境，或需要完整本地语音能力的用户。

发布前必须确认压缩包实际包含并通过验证：

- Windows 可执行入口和 Python 运行环境；
- React 前端生产构建；
- FastAPI 后端和 SQLite 本地数据；
- FFmpeg；
- 本地语音转写模型；
- 匿名说话人分离运行时及模型。

## 使用方法

1. 下载 ZIP 并完整解压到有写入权限的本地目录。
2. 不要直接在压缩包内运行。
3. 双击 `ADS会议智能体.exe`。
4. 等待健康检查完成并自动打开浏览器。
5. 默认访问地址为 `http://127.0.0.1:8000/`。

## 重要说明

- 本产品默认在本机保存会议、任务、模型配置、音频和审计数据。
- 使用在线模型时，API Key 由用户自行配置并保存在本机。
- 不要把包含真实数据库、音频、日志、备份或密钥的运行目录公开上传。
- 完整版不等于所有真实模型、真实音频和所有电脑环境均已验收；以本次 Release 中列出的实测结果为准。
