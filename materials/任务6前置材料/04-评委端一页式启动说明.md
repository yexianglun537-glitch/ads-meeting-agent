# ADS 会议智能体一页式启动说明

## 运行条件

- Windows 10/11 x64；
- Python 3.11–3.14 的任一 64 位版本；
- 不需要 Node.js、npm、PowerShell、Rust、Cargo 或管理员权限；
- 首次启动不需要联网安装 Python 依赖。

## 启动步骤

1. 将 `04- ADS会议智能体源代码.zip` 完整解压到本地目录。
2. 不要直接在压缩包预览窗口中运行。
3. 双击 `启动项目.bat`。
4. 第一次启动会创建 Python 虚拟环境并从包内安装离线依赖，请保持窗口打开。
5. 健康检查通过后，浏览器自动打开：

```text
http://127.0.0.1:8000/
```

如果 8000 已被占用，程序会自动使用 8001–8010 中第一个可用端口。请以启动窗口显示并打开的地址为准。

## 建议演示方式

轻量源码包可以使用本地规则和文字输入完成完整主流程：

```text
创建会议 → 查看会前简报 → 开始会议 → 输入发言
→ 处理超权决策 → 结束会议 → 确认行动项
→ 写回 ADS → 查看审计来源
```

轻量源码包不包含 FFmpeg、本地语音转写、说话人分离运行时或语音模型。设置页显示本地语音组件不可用属于正常情况，演示时使用文字输入即可。

## 停止程序

返回启动窗口并按 `Ctrl+C`。不要在数据写入过程中直接关闭电脑。

## 无法启动时

1. 确认 ZIP 已完整解压；
2. 确认 Python 是 3.11–3.14、64 位；
3. 确认 `backend\wheelhouse` 没有被删除；
4. 保留启动窗口中的完整错误信息；
5. 没有兼容 Python 或需要完整本地语音时，使用完整 Windows x64 版：

<https://github.com/yexianglun537-glitch/ads-meeting-agent/releases>
